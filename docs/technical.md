# Технические подробности

## Пакет и процессы

Имя репозитория и заголовок: Hermes Russian Translate. Технический ID сохранён **hermes-ru-translator**, поэтому папка установки называется именно так.

Backend содержит REST-маршруты перевода, статуса, управления моделью и чтения кэша. Старый инструмент `ru_catalog_apply` оставлен как явно отключённый: запись исходного каталога не производится. Зарегистрированы инструменты `ru_translate`, `ru_translate_status`, `ru_catalog_apply`; хуки и middleware агента не регистрируются.

Только по явной загрузке стартует один локальный `llama-server` на **127.0.0.1:18961**, с ключом доступа собственного runtime. Порт не открывается наружу. Наличие посторонней службы на этом порту считается ошибкой, её плагин не присваивает и не останавливает. Перед выгрузкой сверяются PID, время создания, executable и аргументы. Завершать чужие `python` или `llama-server` по имени запрещено логикой плагина.

Смена пункта в списке моделей не запускает процесс; открытие Hermes читает статус. При включённом переводе и загруженной модели новые подходящие видимые фрагменты переводятся автоматически. HTTP-запросы inference идут на loopback, без системного proxy и без перенаправлений.

## Конфигурация

Файл: `HERMES_HOME/ru-translator/runtime.json`. `HERMES_HOME` берётся из одноимённой переменной; иначе Windows `LOCALAPPDATA/hermes`, иначе `~/.hermes`. Кэш и receipt находятся внутри этого home. Выпуск рассчитан на один home/процесс переводчика; динамическая изоляция одновременно обслуживаемых именованных профилей в общем gateway не реализована и не заявляется. Используется один фиксированный loopback-порт.

```json
{
  "schema_version": 1,
  "device": "cpu",
  "cpu_threads": 4,
  "gpu_layers": 99,
  "profiles": {
    "q8": {
      "server": "../plugins/hermes-ru-translator/vendor/llama-cpu/llama-server.exe",
      "model": "../plugins/hermes-ru-translator/models/Hy-MT2-1.8B-Q8_0.gguf"
    }
  }
}
```

Относительные пути считаются от папки `runtime.json`, `~` раскрывается. URL, UNC-пути, неизвестные поля/профили и замена встроенных хешей конфигурацией не допускаются. CPU использует `-ngl 0`, максимум 8 потоков. GPU использует явно настроенные слои; `gpu_device` необязателен и только при его указании передаётся `--device`.

Для STQ/Stream в `profiles` нужны оба явно заданных пути `server` и `model`. Их ожидаемые хеши/размеры закреплены в `hymt_runtime.py`; произвольные веса не будут молча приняты. Если нужен другой квант, потребуется отдельный проверенный профиль, а не переименование файла.

## Сохранность текста и кеша

Переводчик выделяет технические литералы механически, переводит окружающую прозу и возвращает литералы без изменения. Выход применяется как текст, не как HTML. Ответы с испорченной кодировкой отбрасываются. Это снижает риск повреждения команд, но не гарантирует идеального смысла машинного перевода.

Кэш SQLite находится в `cache/ru-translator/cache.db`; Desktop дополнительно хранит ограниченную проекцию готовых переводов. Хеш зависит от исходного текста, языка и ревизии модели/алгоритма. Локальная база не зашифрована. На странице браузера могут быть личные тексты: их перевод также обрабатывается локально и может быть сохранён в SQLite. Плагин не угадывает «секретность» текста и не отправляет его внешнему переводчику.

UI-адаптер зависит от разметки Hermes Desktop 0.23.1. Он не является поддерживаемым SDK-контрактом и не удовлетворяет правилу8 официального каталога. Это раскрыто в README. Не переписывает исходные манифесты/файлы/инструкции навыков. SDK официально используется для вкладов панели, REST, хранилища и согласованного выполнения кода в гостевой странице браузера.

При смене страницы/отключении поздние результаты не применяются. Уже отправленный запрос к локальной модели может закончиться: физическое прерывание HTTP на границе текущего SDK недоступно. Это не означает повторную отправку ответа на другую страницу.

## Подтверждённые границы выпуска

Рабочая исходная установка проверена пользователем на Windows/Hermes0.23.1/GPU. Публичная копия дополнительно получила независимый review, переносимые конфигурации и изолированные тесты. Установщик проверен на временных поддельных архивах и метаданных плюс PowerShell `-DryRun`; полной загрузки ещё2ГБ и теста на каждом ноутбуке не было. Числа задержки из одной мощной машины не являются обещанием скорости для слабого CPU.

Публикация в GitHub не равна одобрению в каталоге Hermes. Мы просим официальный display-text provider hook в существующем upstream-обсуждении; до появления/принятия такого API каталог остаётся отдельным незавершённым шагом.
