## Host and development dependencies

- [Hermes Agent / Desktop SDK](https://github.com/NousResearch/hermes-agent): MIT; used through imports and the installed host. Core source is not bundled.
- [React](https://github.com/facebook/react), React DOM: MIT. React is external in `desktop/plugin.js`, supplied by Hermes; React DOM is a development-test dependency.
- [nanostores](https://github.com/nanostores/nanostores), [@nanostores/react](https://github.com/nanostores/react): MIT; development tests. Production imports state helpers from Hermes' SDK.
- [esbuild](https://github.com/evanw/esbuild): MIT, development build tool, not bundled.
- [jsdom](https://github.com/jsdom/jsdom): MIT, development tests, not bundled.
- [psutil](https://github.com/giampaolo/psutil): BSD-3-Clause, used for verifying ownership of the local runtime process.
- FastAPI (MIT) and Pydantic (MIT) are used by the installed Hermes API host and Python tests.

See each dependency's package license for its exact terms and transitive notices. `package-lock.json` pins development packages; no `node_modules` is published.

## Optional manually configured profiles

The STQ profile expects a particular compatible-header copy of the official 1.25-bit model; it is not included or generated by the main installer. The reference engine work is [llama.cpp PR #27377](https://github.com/ggml-org/llama.cpp/pull/27377). StreamRevise uses [febilly/Hy-MT2-1.8B-StreamRevise-v4-GGUF](https://huggingface.co/febilly/Hy-MT2-1.8B-StreamRevise-v4-GGUF) at revision `e831109ad7153a2476d298f2cb14ab930b5e9b4f`. Neither optional engine nor optional model is distributed here. Obtain and follow their own source licenses before use/distribution.
